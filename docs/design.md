# 10-Second Command 設計書

このファイルはゲーム設計の「正」となる文書です。実装と食い違ったら、どちらが正しいかを決めてから両方をそろえてください。

数値には **(暫定)** が付いています。試作で調整する前提の叩き台です。

---

## 1. コンセプト

- **ジャンル**:フェイズ制(プロット式)の戦術シミュレーション。2D、ブラウザで動作。
- **一言で**:時間の止まった戦場で、次の10秒を「プログラム」する。
- **ターゲット**:じっくり考えたいが、従来の RTS の操作速度にはついていけない人。Into the Breach や Frozen Synapse のような「読みが当たる気持ちよさ」が好きな人。
- **コア体験**:正面の撃ち合いでは何も決まらない。数で抑え込み、側面を取ったときに一気に決まる。それを10秒単位で組み立てる。

## 2. 時代設定

- 架空の国家同士の戦闘。実在の国名・部隊名・紛争は使わない。
- 技術水準は **1980〜90年代(冷戦末期)** にそろえる。
  - ドローン、熱線映像装置、精密誘導の歩兵携行ミサイルは登場させない。
  - 歩兵戦闘車(IFV)、使い捨ての軽対戦車火器、迫撃砲は登場する。
- 理由:視界ルール(味方の視界外は見えない)が無理なく成立し、参考にする教範(FM 7-8、FM 7-7J など)と時代がそろうため。

## 3. ゲームの流れ

1. **配置フェイズ**(ステージ開始時のみ)
   コストの範囲内で、配置可能エリアにユニットを置く。敵の初期配置は、味方の視界に入る範囲だけ見える。
2. **計画フェイズ**(時間停止)
   各ユニットに次の実行フェイズの命令を出す(→ 5章)。終わったら「実行」を押す。
3. **実行フェイズ**(10秒)
   敵味方が同時に動く。プレイヤーは見るだけ。10秒たつと停止して計画フェイズに戻る。
   - フェイズの長さは定数にして、後から変えられるようにする(5秒・8秒なども試す)。
4. **勝敗判定**
   敵の全滅または目標地点の確保で勝利(MVP では全滅のみで判定する)。味方の全滅または防衛線の突破で敗北。敗北したらすぐに同じ配置からやり直せる。

## 4. 視界と地形

### 4.1 視界(フォグ・オブ・ウォー)

- 地形(建物、壁、茂みなど)は常に見える。
- 敵ユニットは、味方のいずれかの視界に入っているときだけ見える。
- 視界はユニットの向いている方向に **120° の扇形**、距離は兵科ごと(→ 6章)。
- 視線は硬い遮蔽物と建物でさえぎられる。茂みは視線を通すが、中にいる目標の発見距離を **半分** にする。
- **最終確認位置**:視界から消えた敵は、最後に見えた位置にゴースト表示する。「何秒前か」も表示する。
- **発砲による暴露**:発砲したユニットは、その後 **2秒間** 発見距離が2倍になる。視界外から撃たれた場合は、射撃方向がおおまかな範囲として表示される。
- **迫撃砲**:自分の迫撃砲の着弾予定位置は見える。敵の迫撃砲の着弾予定位置は見えない。ただし着弾の **0.5秒前** に飛翔音の予兆が出て、その付近の味方は自動で反応する。

### 4.2 地形の種類

| 種類 | 例 | 射撃から守る | 視線をさえぎる |
|---|---|---|---|
| 硬い遮蔽 | 壁、瓦礫、土塁 | ダメージ ×0.2 | さえぎる |
| 軟らかい遮蔽 | 木柵、車両の残骸 | ダメージ ×0.5 | さえぎらない |
| 隠蔽 | 茂み、草むら | 守らない | 発見距離を半分にする |
| 開けた地面 | 道路、野原 | 守らない | さえぎらない |
| 建物 | 家屋 | 進入不可(v1) | さえぎる |

### 4.3 遮蔽の方向性(最重要)

- 遮蔽は **方向を持つ**。遮蔽物の正面方向から **±60°** の範囲から撃たれたときだけ効果がある。
- それ以外の方向(側面・背面)から撃たれたら、遮蔽はないものとして扱う。
- これにより「一方が抑え込み、もう一方が回り込む」行動に、確実な見返りが生まれる。

## 5. 計画フェイズで出せる命令

| 命令 | 内容 |
|---|---|
| 経路 | ウェイポイントを順に打つ |
| 待機 | ウェイポイントごとに「ここで○秒待つ」 |
| 向き・射界 | 扇形で、向く方向を指定する |
| 交戦姿勢 | **自由射撃**(見えた敵を撃つ)/**射撃禁止**(撃たれるか発見されるまで撃たない。待ち伏せ用) |
| 接触後の方針 | **前進**/**保持**/**離脱**(→ 7章) |
| 火力の集中(オプション) | 優先して撃つ敵を1つ指定する。指定しなければ一番近い敵を撃つ(→ 8.1) |
| 兵科固有 | 迫撃砲の射撃(位置と発射時刻)、IFV の乗車・下車、対戦車火器の使用許可など |

- 条件分岐(「敵を見たら止まる」など)は v2 以降で検討する。
- 計画フェイズには **タイムラインのスクラブ** を用意する。0〜10秒のスライダーを動かすと、味方の予定位置がゴーストで表示される。敵の未来は表示しない。

## 6. ユニット

すべてのユニットは **位置と向き** を持つ。

### 6.1 射撃班(歩兵)

- 4人で1ユニット。耐久100(1人25)。人数が減ると火力も比例して下がる。
- 移動速度 2.5 m/秒、伏せ移動 0.8 m/秒 (暫定)
- 視界距離 120 m (暫定)
- 基本火力 10/秒。有効射程 100 m まで減衰なし、200 m で 0 まで直線的に減衰 (暫定)
- オプション装備:**軽対戦車火器**(使い捨て、1発)
  - 射程 150 m、構えに 1 秒、ダメージ 120 (暫定)
  - IFV の正面装甲にはほぼ効かず、側面・背面なら撃破できる(→ 6.4)。

### 6.2 スナイパー

- 1人で1ユニット。耐久25。
- 移動速度 1.2 m/秒 (暫定)
- 視界距離 250 m。向いている方向に細長い射線を持つ (暫定)
- **クールタイム制**:1発撃つと装填に 8 秒 (暫定)。フェイズの区切りとは無関係。
- 射線に敵が入ってから撃つまでの **反応時間 0.4 秒** (暫定)。走り抜ける、煙で切るなどの対抗手段を残すため。
- 命中で目標の耐久 −25(射撃班なら1人分)、制圧値 +50。

### 6.3 迫撃砲班

- 3人で1ユニット。耐久75。**移動できる**。
- 移動速度 1.5 m/秒 (暫定)
- 撃つには **展開** が必要(4秒)。移動するには **撤収** が必要(3秒)。展開中は移動できず、移動中は撃てない (暫定)
- 射撃は「着弾位置」と「発射時刻(フェイズ内の何秒目か)」で指定する。
- 発射から着弾まで **3秒**。フェイズの区切りをまたいだ弾は、次の計画フェイズに着弾予定マーカーとして残る(自軍のもののみ表示)。
- 射程 50〜400 m、弾数 8発、連続発射の間隔 2秒 (暫定)
- 着弾効果:半径 8 m でダメージ(中心 60、外縁 0 へ減衰)、半径 15 m で制圧値 +40。遮蔽物は乗り越えるが、遮蔽内の目標へのダメージは ×0.5 (暫定)

### 6.4 歩兵戦闘車(IFV)

- 耐久200。射撃班を1つ乗せて運べる。
- 前進 6 m/秒、後退 2 m/秒、旋回 45°/秒 (暫定)
- 視界距離 150 m (暫定)
- 機関砲:歩兵に対して火力 20/秒、制圧値 +40/秒 (暫定)
- **4方向の装甲**:正面・左右側面・背面で被ダメージ係数を変える (暫定)

  | 攻撃 | 正面 | 側面 | 背面 |
  |---|---|---|---|
  | 小銃 | 無効 | ×0.1 | ×0.2 |
  | 機関砲 | ×0.3 | ×1.0 | ×1.2 |
  | 軽対戦車火器 | ×0.2 | ×1.0 | ×1.5 |
  | 迫撃砲(直撃) | ×0.5 | ×0.5 | ×0.5 |

- 乗車・下車にそれぞれ 3 秒 (暫定)

## 7. 歩兵の状態遷移

教範のバトルドリル「直接射撃への対処」を元にしている。撃たれたら撃ち返しながら遮蔽を取り、その後に指揮官が「突撃するか、離脱するか」を決める、という構造。

```
通常行動(経路移動・待機)
   │ 敵を発見、または撃たれた
   ▼
接触(反応遅延 0.5秒)
   ├─ 遮蔽内にいる ────────────→ 応射
   └─ 遮蔽外にいる → 遮蔽へ退避 ─(到着)→ 応射
                       └ 近く(3秒で届く範囲)に遮蔽がなければ伏せ
   ▼
制圧値の判定(動揺/制圧/釘付け)
   ▼
接触後の方針(計画フェイズで事前に指定)
   ├─ 前進:制圧値 40 未満なら経路を再開
   ├─ 保持:その場で射撃を続ける。敵が見えなければ最終確認位置へ制圧射撃
   └─ 離脱:釘付け(100)でなければ指定経路で後退。速度 ×0.7
```

- 自動で行うのは「接触」から「制圧値の判定」まで。プレイヤーが決めるのは「接触後の方針」だけ。
- 反応遅延の 0.5 秒の間は、それまでの行動(経路移動など)を続ける。
- 退避先は、脅威の方向に正面が向いた遮蔽に限る(向きの合わない遮蔽に逃げ込んでも守られないため)。
- 敵が見えず、撃たれもしない状態が **3 秒** 続いたら接触を解き、元の経路に戻る (暫定)。
- 離脱を始めたら、前進用の経路は取り消す。離脱経路が指定されていなければ、その場で保持と同じ動きをする。
- 経路移動中・離脱中も、射撃禁止でなければ撃ち返す。
- 制圧射撃(見えていない最終確認位置への射撃)は、ダメージは与えず、制圧値だけを与える(通常の半分)。

## 8. 戦闘計算

### 8.1 ダメージは確定(乱数なし)

- 命中率のような乱数は使わない。「火力 × 係数」を毎ティック積算する。
- 同じ入力からは必ず同じ結果になる(リトライやリプレイのため)。

| 係数 | 値 (暫定) |
|---|---|
| 目標が硬い遮蔽の内側(正面方向から撃たれた) | ×0.2 |
| 目標が軟らかい遮蔽の内側(正面方向から撃たれた) | ×0.5 |
| 目標が開けた地面に伏せている | ×0.6 |
| 目標が移動中 | ×0.8 |
| 目標が開けた地面に立っている | ×1.0 |
| 射手が動揺(制圧値 40〜69) | ×0.7 |
| 射手が制圧(制圧値 70〜99) | ×0.3 |
| 射手が釘付け(制圧値 100) | 盲射のみ(下記) |

- **盲射**:釘付けでも、効いている遮蔽の内側からなら、顔を出さずに銃だけ出して撃てる。ダメージ ×0.1、与える制圧値 ×0.2 (暫定)。遮蔽の外で釘付けなら撃てない。
- **火力の集中**:指定した敵を撃てないときは、その敵の最終確認位置へ制圧射撃する。最終確認位置もなければ一番近い敵を撃つ(指定は残し、撃てるようになったら戻る)。指定した敵が倒れたら指定を解除する。
- **射撃できる相手**:味方のいずれかの視界に入っている敵と、直前にこちらを撃ってきた敵だけ。射程内で射線が通っていること。
- **射線**:建物と硬い遮蔽は弾をさえぎる。ただし、射手か目標が身を隠している遮蔽物(縁から **1.5 m** 以内にいる遮蔽物 (暫定))は、その越しに撃てるのでさえぎらない。軟らかい遮蔽は弾を通す(被害は ×0.5)。
- **遮蔽の正面**:遮蔽物のどちら側にいるかで自動的に決まる(身を隠している側から見て、遮蔽物のある方向が正面)。

### 8.2 制圧値(0〜100)

- 撃たれている間に増える。射撃班1つから受けると **+25/秒** (暫定)
- 遮蔽の内側でも増加は **×0.8** までしか減らない。守られていても頭を上げられない状態を作るため。
- 与える制圧値も、射手の残り人数と状態(動揺 ×0.7、制圧 ×0.3)に比例する。抑え込まれた側は相手を抑え込めなくなる。
- 制圧射撃は、最終確認位置から半径 **5 m** (暫定) 以内にいる敵に効く。最終確認位置への射線が通っていること。
- **回復を止める射撃**:平常か動揺の射手(制圧値 70 未満)の射撃だけが、相手の回復を止める。制圧状態の射撃や盲射は制圧値を加えるが、回復の1秒の待ちを止めない。互いに抑え込み合って全員が釘付けのまま固まるのを防ぐため。
- 撃たれなくなってから 1 秒後に回復が始まり、**−20/秒** で下がる (暫定)
- しきい値:

  | 制圧値 | 状態 | 影響 |
  |---|---|---|
  | 0〜39 | 平常 | なし |
  | 40〜69 | 動揺 | 火力 ×0.7。前進方針でも経路を再開しない |
  | 70〜99 | 制圧 | 火力 ×0.3。離脱以外の移動をしない |
  | 100 | 釘付け | 射撃も移動もしない |

## 9. 設計目標(自動テストにする)

数値そのものより、以下の挙動を満たすことを優先する。数値を変えたら必ずこのテストを通すこと。

1. **1対1、互いに硬い遮蔽の内側で正面から撃ち合う**:どちらも 60 秒以内には全滅しない(にらみ合いになる)。
2. **2対1、撃たれる側が遮蔽の内側**:撃たれる側は 2〜4 秒で制圧状態(制圧値 70 以上)になる。
3. **側面から撃つ**:制圧された目標を側面から撃つと、遮蔽が無効になり、10 秒以内に全滅する。
4. **決定性**:同じ初期状態と同じ命令からは、何度実行してもまったく同じ結果になる。

## 10. 開発の段階

### MVP(最初の試作)

- マップ1枚(200 m × 150 m 程度、遮蔽物いくつか)
- 射撃班 2対2 のみ
- 計画フェイズ:経路、待機、向き、交戦姿勢、接触後の方針
- 実行フェイズ 10 秒 → 停止 のループ
- タイムラインのスクラブ
- 敵は固定の命令(または単純な AI)で動く
- 視界ルールは **まだ入れない**(全部見える状態で撃ち合いの挙動を確かめる)
  - ただし、ユニット自身が敵に気づく判定(扇形 120°・視界距離・射線)は MVP から入れる。プレイヤーの画面には敵が常に表示される。

### 次の段階(順番に)

1. 視界ルール(フォグ、最終確認位置、発砲による暴露)
2. スナイパー
3. 迫撃砲班
4. IFV と軽対戦車火器
5. 敵 AI の「性格」(突撃型、待ち伏せ型など。プレイヤーに表示する)
6. ステージを複数とステージ評価
