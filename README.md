# 10-Second Command(仮題)

10秒ごとに時間が止まる戦場で、次の10秒の動きを「プログラム」する、フェイズ制の戦術シミュレーションゲームです。ブラウザで動きます。

## 遊び方(MVP 試作)

0. 最初の画面でミッションを選ぶ(ミッション1:農村の石垣、ミッション2:尾根の雑木林=スナイパーあり、ミッション3:丘の裏の砲座=迫撃砲あり、ミッション4:牧草地の装甲車=IFV あり、ミッション5 A/B/C:小村の外れ=敵の性格がちがう3通り、ミッション6:十字路の村=配置を自分で決める、ミッション7:川沿いの村=建物に入れる・配置あり、ミッション8:街道の集落=家にこもって守る、ミッション9:谷の集落=待ち伏せの村を攻める、ミッション10:浅瀬の渡り=敵の IFV と歩兵を受け止める)
   - 「配置あり」のミッションでは、最初に持ち点の中で部隊を好きな数だけ買い(右のパネルの「+」。外すこともできる)、配置エリアの中で部隊をドラッグして置き、「配置完了」を押す
1. 右のパネルか地図上で、命令を出す班を選ぶ
2. 「経路」を選んだまま地図をクリックすると、移動する点を足せる。点ごとに待機秒数も決められる
   - 窓の点線がある建物は、射撃班と狙撃手が入れる。経路で建物をクリックすると、入口まで歩いて中に入る
3. 交戦姿勢(自由射撃/射撃禁止)、接触後の方針(前進/保持/離脱)、必要なら向き・離脱経路・撃つ敵の指定を決める
4. 下のスライダーを動かすと、10秒後までの味方の予定位置が半透明で表示される
5. 「▶ 実行」で10秒進む。止まったら次の命令を出す
6. 勝敗がつくと「リプレイを見る」で最初から見返せる(敵も全部見える)
7. 勝つと星(★1〜3)が付く。目標フェイズ以内で、班を失わず被害を3割以下に抑えれば ★3。一番よい成績はミッション選択画面に残る

敵は、味方のだれかの視界(扇形)に入っているときだけ表示されます。見えなくなった敵は、最後に見えた場所に「○秒前」と表示されます。

スナイパー(ひし形)は、「射界(向き)」で指定した細い扇形の中に入った敵だけを1発ずつ撃ちます。撃つと位置がばれます。

迫撃砲班(四角)は「展開する」で撃てる状態にし、「迫撃砲の射撃」で着弾させたい場所をクリックします。味方のだれかがその場所を見ていないと、遠くへずれます。

IFV(長方形)は射撃班を1つ乗せて運べます(「経路の終点で下車させる」)。小銃は効きません。対戦車火器(オレンジの四角を持つ班)を、横か後ろから2発当てると撃破できます。IFV の機関砲で撃たれ続けた石垣は崩れます。

射撃班は発煙手榴弾を2個持っています(「発煙手榴弾」で地図をクリック、30 m まで)。迫撃砲は8発のうち2発を発煙弾にできます。煙は視線をさえぎりますが、弾は通ります。

ヒント:正面から撃ち合っても決着はつきにくい。敵から見えない道を通って側面に回り込もう。

## もともとの構想

1. **計画**:時間が止まっている間に、各部隊の移動経路や、敵と接触したときの方針を決める
2. **実行**:「実行」を押すと、敵味方が同時に10秒間だけ動く
3. **停止**:10秒たつと再び時間が止まり、次の計画へ

## 起動方法

[Node.js](https://nodejs.org/) が必要です。

```
npm install
npm run dev
```

表示された URL(例:http://localhost:5173)をブラウザで開いてください。
